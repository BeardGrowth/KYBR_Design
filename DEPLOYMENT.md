# KYBR Marketing AI — Website Redesign

Independent, responsive marketing website prototype for **KYBR**, designed separately from the production site at kybrmarketing.ai.

## Preview
This is a static site. Open `index.html` in a browser, or deploy this repository to Netlify.

### Netlify deployment
1. In Netlify, choose **Add new project → Import an existing project**.
2. Connect GitHub and select `BeardGrowth/KYBR_Design`.
3. Set **Build command** to blank, **Publish directory** to `.`.
4. Deploy. Netlify will provide a temporary `.netlify.app` URL.

No domain change is required to preview. Do **not** point kybrmarketing.ai to this repository until the design, claims, contact form and integrations have been reviewed.

## Contents
- `index.html`: homepage, interactive dashboard concept, enterprise, product sections, FAQ and demo form
- `styles.css`: premium navy / teal / purple responsive styling
- `script.js`: mobile navigation, demonstration data filters, solution tabs and mailto form

## Important prelaunch notes
- **All dashboard metrics are illustrative demo data**, not verified business results.
- The **44-location** illustration is a sales scenario and does not claim 44 existing customers.
- Replace concept dashboard elements with real screenshots/features as product readiness is verified.
- The demo form currently prepares an email in the visitor's email application; it is not integrated with CRM or email delivery. Verify `hello@kybrmarketing.ai` as a monitored address before launch.
- Review legal disclosures, privacy policy, SEO metadata, accessibility and tracking before production deployment.
