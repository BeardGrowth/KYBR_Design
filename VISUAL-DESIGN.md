# KYBR Website Visual System — November 2026

## Approved creative direction
- Use the official KYBR wordmark and its deep purple **#220F43** with turquoise **#05C4CD**.
- Warm off-white backgrounds, editorial spacing, readable typography, large friendly dashboards.
- Human-centered real photography paired with clean, enterprise-grade interface visuals.
- No gratuitous arrow icons, neon sci-fi surfaces or unsupported business claims.
- Core story: one Growth Operating System for content, marketing, relationships, tasks, outreach, reputation, automation and reporting.
- Three offers: platform, managed implementation/marketing, enterprise.

## Implemented in the repository
- `index.html`: refined product-led homepage, dashboard-inspired hero, four visual workspace previews, illustrative business application cards, onboarding and conversion flow.
- `visual-2026.css`: updated KYBR design tokens, presentation, responsive workspaces and case-story treatment.
- `growth.js`: interactive dashboard tabs, CTA navigation and Netlify form behavior.

## Accuracy and approvals
All 10 concept images are AI-generated; they do not depict actual employees, clients or patients. All dashboard quantities, sponsor companies, reviews, event details and performance values in image concepts are fabricated examples and must never be framed as actual results, partnerships, reviews, user accounts or production product screenshots. Some concepts also contain invented brand marks and location names.

The homepage currently uses editorial placeholder photography and coded UI mockups. Replace placeholders with approved, authentic photography and validated product captures before public launch. Secure appropriate photo and patient/resident consents, commercial usage permissions and actual customer approvals. Do not use healthcare or patient images publicly without the applicable consent/authorization.

## Launch quality gates
1. Confirm that Netlify deployed the latest `main` branch and test iPhone/desktop layouts.
2. Test every workspaces tab and link navigation.
3. Replace placeholder photography, concept graphics and unverified claims.
4. Validate the demo request form and notification delivery via Netlify.
5. Confirm official logos for each customer brand; do not use image-generated logos as official.
6. Keep the preview noindex. Remove staging SEO restrictions only when publishing the verified production website.
7. Audit color contrast, accessible labels, mobile load speed and media licensing.
